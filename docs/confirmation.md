# Reserved confirmation and later-stage requirements

**Not an executed or fully ready confirmatory study.** Development must first
validate measurement headroom and the architecture. Seeds 12001–12008 are
reserved and must not be generated by development. Existing EXP002 confirmation
seeds are also unused by this replacement suite. No retry or adaptive selection
from these worlds is allowed. There is no automatic confirmation command.

After successful development, make a separate immutable protocol commit with
selected configuration, code/dependency hashes, exposure/compute budgets,
primary metrics, minimum effects, paired intervals and exclusion rules. Confirm
Stage0/1 on all eight independent worlds; use paired per-world effects with
uncertainty. A functional benefit must exceed 10 percentage points for learned
versus frozen filters, and 3 points for causal ablations with lower confidence
bound above zero. Ensure those effects have headroom before freezing. Separate
acute interventions from retrained ablations. Fix a corruption distribution on
fresh development worlds if clean tests saturate. Do not relabel the current
exploratory grid as preregistered confirmation.

Stage2 additionally requires an implemented, validated higher composition task
and learner. Freeze old probes before further learning; record old outcomes,
arbitrary episodic tags, old items/subchunks, novel context and novel relation
combinations. Measure 1-cosine, linear CKA, predictive geometry alignment,
category tuning, cross-context reuse, activity sparsity and effective code size.
Include fixed category/readout controls and targeted versus matched random
lesions. Generalization without preserved tags supports a weaker claim than
preserving individual experience. Prediction and tag accuracy must be adequate
before comparing reorganization. Changed activity alone is not abstraction.

Stage3 requires valid Stage1/2. Fix task/probes/outcomes, then separately compare
continued local plasticity, fully frozen learning, and unconstrained synaptic
noise, with matched nonchunking controls. Perturbation is not endogenous drift.
Measure functional retention with the actual reader, neural/geometry change and
noise-dose response. Test whether learned abstraction causally changes tolerance
by matched lesions/ablations. A separate acquisition experiment is needed to
ask whether drift helps abstraction, preserving comparable learning capacity.
No projection, old-output oracle, or output-preserving rejection is allowed.
None of these stages is implied complete by a passing unit test or saved snapshot.
